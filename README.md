# agent-work

一个给 dsh-superagent 练手用的小仓库。

## 它是什么

这个仓库的用途只有一个：让接进来的 AI 同事（dsh-superagent）有一个真实的目标仓库可以读、可以改、可以开 PR。

## 怎么试

在 Issue 里 @ 它，说清楚要改什么。例如：

> @ling5717 把 index.html 里的标题改成 "Hello, agent"

它会自己开分支、改文件、开 PR，并在 Issue 里回复你。

## 结构

- `index.html` — 一个最小的静态页面，用来测试文案/样式类改动
- `AGENTS.md` — 给 coding agent 的仓库级说明
- `notes/` — 随手记的笔记，测试文档类改动
